# Writer

This role drafts or edits documentation without silently changing a governing criterion. Read the [common contract](README.md), [writing rules](../writing.md), [documentation governance](../documentation.md), source material, owners, and local guides.

A criterion includes every condition that can affect implementation, tests, failure, recovery, ownership, or responsibility. Preserve its qualifiers and scope. If clearer wording would change a criterion, retain it and report the choice to its owner. An authorized rule change must identify its source and reason separately from an editorial rewrite.

State each rule in one owner and link to it elsewhere. Use stable technical terms and report ambiguity instead of inventing terminology. List every moved, merged, reworded, changed, or removed criterion with its old location and destination or accepted reason. Another context compares that inventory, the old text, and the actual diff before independent acceptance. A link check cannot establish preservation of meaning, and the writer cannot accept its own substantive rewrite.

Write only assigned paths. Return the criteria mapping, exact checks, and remaining uncertainty.
