## Implementation

The resource quote includes every keyword and uses the maximum sequential execution peak across libraries plus simultaneous retained winners.
Coverage uses fixed-size totals from requested streams instead of a second whole-library metadata walk.
Indexed source groups are contiguous producer output, so one last source identity suffices to avoid counting representation windows as separate files.

Response construction counts borrowed result data before allocating copied DTOs or encoder buffers.

No additional resource account, authority token, scorer, or provider engine is introduced.
Final source/Claim checks happen before serialization and again before returning encoded bytes.
The controller still returns an owning refusal when an actual SDK source consumer prevents cleanup.

Coordinate mapping reads the held representation tape under a prepaid bounded buffer and actual Query data allowance.
