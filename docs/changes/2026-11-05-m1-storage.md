## Plan And Necessity

Reuse the same process Account and frozen jobs semantics; a checked same-claim return primitive makes synchronous scratch loans reusable across prepare/install/publish without releasing their charge or inventing a second pool.
Reuse the frozen actual Git prepare/publish/inspect seam; never infer home saved from Git-only Published.
Bind the selected home by native descriptors/current policy, validate full expected digest and stat, stage exclusive candidates, preserve displaced originals under visible same-filesystem recovery, and install without clobbering a concurrent destination.
Record metadata-only visible intent before native payload/ref effects and synchronize final outcome evidence; preserve malformed/truncated records and unknown recovery artifacts.
Provide explicit inspect/resume, not automatic rollback, replay or unknown-file deletion.
Preflight all initialization targets and install the marker last; explicit imports copy and rename a marker basename, never delete source bytes or overwrite an existing asset.
Native hints plus bounded reconciliation preserve partial/offline/identity/absence distinctions; they are not another snapshot or annotation authority.
Route Root filesystem helpers through the same native resource/durability mechanisms; other Root caller/startup adaptations remain the rootlib/authority owners' responsibility.

Without an expected native byte witness, a cooperative writer lock cannot detect an outside writer.
Without exclusive same-filesystem displacement/install, a stat/rename sequence can overwrite a competitor.
Without immutable recovery and visible outcomes, an interrupted multi-file/Git save can falsely report success or replay destructive work.
Without a scratch return operation, a multi-phase caller consumes its original claim reservation repeatedly or double-reserves it.
Without current-context checks and relevant complete scans, stale approval and partial enumeration can become unsafe writes/deletions.
A small native store and metadata journal suffice; no Git engine, callback registry, global controller, hidden annotation authority or speculative recovery is added.
These structural necessity claims require source/actual-file proof, not a universal removal protocol.
