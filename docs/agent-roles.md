# Agent Roles

This document defines the questions and limits of delegated roles. [Change execution](change-execution.md) decides when to use them.

The primary is a position: it owns intent, integration, and progress for one scope. A role is a function. One agent may perform several functions where independence is not required.

## Common Contract

Read the root AGENTS.md, this contract, the named owners, and affected local guides. Derive expectations from source intent and accepted decisions. Inspect direct artifacts. Work only within the assigned paths and effects.

Return the conclusion, evidence pointers, exact checks and results, changed paths, unresolved findings, and decisions needed. Report missing capacity or authority before dependent work. Do not delegate again unless the assignment permits it.

## Functions

| Role | Question | Limits |
| --- | --- | --- |
| Researcher | What does independent evidence establish? | State sources, dates, uncertainty, and inference. Research does not approve design. |
| Consultant | Is the need clear and the route justified? | Challenge assumptions and compare simpler alternatives before costly commitment. Return governing choices to the engineer. |
| Test author | Which observation can disprove conformance? | Derive expectations from the owner, not the candidate implementation. State the failure the check must detect. |
| Builder | What coherent change meets the accepted contract? | Stay within assigned paths. Preserve contract-derived checks and unrelated work. |
| Writer | Does the text preserve meaning and make the owner clear? | Map moved or changed criteria. Obtain another context's check of a substantive rewrite. |
| Reviewer | Is the actual result correct, complete, simple, and aligned? | Read the artifact and surrounding consumers. Do not edit the work under review. |
| Auditor | Do source intent, decisions, owners, and observed behavior agree? | Trace consequential claims to evidence. A finding or report cannot amend authority. |

## Independence

Self-review is useful but is not independent review. A new role name or fresh context does not erase authorship. A co-author cannot independently accept the same result.

A reviewer reports actionable findings by severity. Name the affected rule, consequence, evidence, and smallest sufficient correction. Distinguish introduced defects from existing findings.

If there are no actionable findings, say so and state the review's limits. Independent agreement remains a judgment, not proof that no defect exists.
