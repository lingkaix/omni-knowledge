# Omni Grep

This repository is a product-neutral engineering baseline for work by humans and agents. The product, language, architecture, and deployment model are deliberately undefined.

## Start Here

Read [AGENTS.md](AGENTS.md) for the execution contract and [CONTRIBUTING.md](CONTRIBUTING.md) for the contribution procedure. The [documentation map](docs/README.md) locates principles, workflow, verification, and writing rules.

The baseline is usable without a technology stack. It defines how to investigate, decide, build, verify, review, and preserve context.

## Current State

The repository contains engineering guidance and Git ignore rules. It contains no product implementation, runtime dependencies, build system, test suite, or deployment configuration.

When product work starts, record the user need and acceptance examples before choosing technology. Follow [documentation governance](docs/documentation.md) for any governing contract. Use [toolchain guidance](docs/toolchain.md) when a runtime becomes necessary.
