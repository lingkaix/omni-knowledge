# Application Assets

`preview.html` is the controlled preview frame, and `vendor/` contains the offline rendering scripts and their licenses.
`foundations/` contains the engineer-requested original initialization sources, provenance, and retained license material.
`brand/` contains the soft-green logo and macOS icon adapted from the engineer's supplied vector design.
`icons/` contains the verified Lucide subset used by GPUI Kit; unrelated upstream icon assets are excluded.
Do not grant imported document content permission to execute scripts through these assets.
