左侧显示本机可选工具的检测结果和安装入口；右侧是离线使用指南。点击顶部绿色标志或 返回知识库，即可回到原来的检索结果和文件预览。
快速开始怎么检索文件与预览依赖与模型AI Agent 与 CLI目录、备份与嵌套当前限制遇到问题

快速开始

  1. 准备知识库目录。 点击顶部 Library 文件夹图标展开位置面板，填写文件夹路径，例如 ~/Documents/Omni Knowledge。Initialize 创建模板并建立第一个文字索引；已有知识库使用面板中的 Choose 或 Open。位置面板平时收起，底部左侧显示当前知识库名称与路径。
  2. 纳入原始文件。 目录树旁的 Add files 按钮把所选文件复制到底部状态栏标明的目标文件夹（未选择文件夹时为知识库 root），保留外部原件，也不会覆盖同名文件。你也可以直接用 Finder 或 AI Agent，把文件放进知识库的任意合适目录。
  3. 添加可检索的说明。 选中文件后，点击预览栏的 File details 按钮，在带标签的 Tags 和 Notes 中填写标签与备注，再点击 Save tags and notes。内容写入当前知识库的独立 JSON 记录，不修改原文件；面板显示保存位置，并可在 Finder 查看已保存的记录。重新选中文件并打开 File details，即可看到已保存的内容。切换文件前请先保存；未保存内容不会跨文件保留。编辑器平时收起，再次点击按钮可收起它；选择另一个文件时也会收起。这对二进制文件、图片和无文字内容的文件尤其有用。
  4. 外部编辑后刷新。 在 Finder 或编辑器中添加、修改、移动或删除文件后，点击 ↻ Refresh index 图标。检索读取最近成功发布的索引；后台会定期检查文件元数据变化，仍需你主动刷新索引。
  5. 检索并查看证据。 输入查询，点击搜索框内的 Search options，按需选择搜索方式或填写标签，按 Enter 或点击 Search。下拉菜单支持方向键、Enter 和 Escape。未搜索时，目录树直接读取磁盘上的文件，包括新文件和空文件夹，展开时按需加载；列表采用虚拟化，没有 1,000 个文件的浏览上限。搜索后显示索引匹配过滤视图；点击搜索输入框尾部的清除按钮，同时清空查询和标签，立即回到完整浏览。点击三角形展开或折叠目录，点击文件查看预览。搜索结果中的 #数字 保留原检索排名；同一文件的多个匹配按返回顺序列出，保留各自的行号或时间位置。

模板保留 LLM Wiki 和 Open Knowledge Format 的原始离线文章，并提供链接到原文的参考概念页。软件负责文件管理、索引和检索；知识摘要、交叉链接和 wiki 的持续维护由你使用的 AI Agent 完成。

底部状态栏平时只占一行，集中显示知识库位置、粘贴／拖入目标、环境状态和索引操作；不再常驻显示文件操作说明或 Preview ready。鼠标悬停在图标或状态项目时，才会临时显示完整提示；移开后恢复单行。提示在自己的布局范围内显示，不会被预览遮挡。信息图标打开“说明与环境”。选中文件后，预览栏始终提供 Quick Look、Open original、Finder 和 File details 按钮；右键文件也能找到这些操作。折叠文件夹和切换指南不会清除当前预览、查询或编辑内容。目录树标题显示文件数，一个文件可能包含多处匹配。

底部左侧的知识库名称与绝对路径共用一个入口，点击可用 Finder 打开该目录。工具、本地模型和 ASR 状态在中间，点击可查看对应的依赖安装或修复说明。索引状态位于最右侧，紧邻 Refresh index；点击“索引过期”或“需要建立索引”可直接刷新当前知识库的索引。修改 Library 面板的路径后，状态检查会跟随新路径；目录树仍显示上一次打开的知识库。输入另一个尚未打开的知识库时，索引区域会引导你先选择 Open 或 Initialize，不会误刷新旧知识库。

状态每 12 秒在后台检查一次；打开目录、建立索引和保存元数据后会再次检查。索引状态比较文件名、大小与修改时间，以及配置和元数据的修改时间；“索引未见变化”不代表逐字节验证。扫描未完成时会明确说明，外部编辑造成索引过期时仍需主动刷新索引。Refresh index 会实际建立索引，不只是检查状态。后台检查不会替你初始化、安装工具或启动模型。

文件操作与输入

右键文件会直接选中该文件，并可复制 macOS 文件对象、复制绝对／相对路径、在 Finder 显示原件，或选择“Move to Trash…”并确认。点击菜单外部（包括右侧预览）或按 Escape 可关闭菜单；直接右键另一个文件可切换目标。复制文件对象可在 Finder 或本应用粘贴；复制路径只是文本。选中文件树后，⌘C 复制文件，⌘V 将剪贴板中的原生文件复制到当前目标文件夹。右键普通文件夹可直接粘贴到该目录，也可以展开或折叠全部目录。独立子知识库会显示 child KB，父库不会进入或写入其内部。

从 Finder 拖入文件会复制原件；在本知识库树内拖动文件到另一个普通文件夹会移动文件。底部状态栏显示粘贴／拖入的目标；拖到文件行时目标是该文件的父文件夹，拖到树的空白区域时是知识库 root。操作仅处理普通文件，同名冲突会明确报错，不会覆盖或自动改名。移动／复制会保留可编辑标签和描述；旧路径元数据保留，操作后仍需刷新索引。

所有文本框使用 GPUI Kit 输入组件。双击选词，⌘A 全选；⌘X／⌘C／⌘V 剪切、复制和粘贴文本；Option+Backspace 删除前一个词，⌘Z 撤销。macOS 顶部 Edit 菜单提供同样的入口。中文输入可先组合、选字，再提交检索。

选择合适的检索方式

方式适合什么问题实际行为
精确标签“只看研究、硬件相关的文件”在 Search options 的 Tags 中输入逗号分隔的标签。所有标签都必须匹配，区分大小写，不做模糊匹配。标签过滤适用于每种检索方式。
Full text · 全文搜索关键词、主题名、中文短语使用已建立的文字索引，综合标题、路径、描述和内容排序。多个词按相关性组合；需要严格原文匹配时使用 Text pattern（Grep）。
Text pattern · 原文模式准确词句、代码符号、正则表达式在索引中的提取文本上验证 Rust 正则表达式，并提供匹配文本行号（转换文档为提取文本行号）；找不到正文时还会检查路径和描述。它读取索引快照，外部修改后需要刷新。
Meaning · 语义换一种说法描述内容，或描述图片／视频画面使用兼容的本地多模态模型和已建立的向量。模型不可用或尚未建立向量时，会给出明确错误。
Text + meaning · 文字与语义同时利用关键词与语义合并 BM25 与语义结果，保留可用的时间证据。仍然需要本地模型和向量索引。
File names & notes · 文件与备注文件名、路径、描述，或浏览所有资产无需模型，包含无法提取正文的文件。空查询也会按当前标签过滤浏览文件。

搜索选项平时收起；非默认搜索方式和标签数量会在入口显示。修改后需点击 Apply 或 Search 才会应用；changes not applied 表示修改尚未生效，显示的结果仍保留之前的条件。搜索失败也会保留之前成功的结果与条件。标签限制只属于搜索，添加文件在目录树旁，索引刷新在底部右侧，知识库位置与语义索引生成选项在 Library 中。

“研究”和“研”不是同一个标签；“Rust”和“rust”也不同。Markdown front matter 中的标签与手工元数据标签会合并。保存会立即写入可编辑标签和备注，不会启动整库索引；面板会区分未保存、保存中、已保存和失败。这里编辑的是独立记录中的标签，不是原文 front matter。之后主动点击 Refresh index，检索才会使用新的标签与描述。原文 front matter 保持不变。

搜索按检索相关性显示文件，不会再被目录名称重新排序。同一文件只占一个主结果，展开可看其他行或时间位置；先显示前 50 个文件，Show 50 more files 可继续加载。语义结果中的 candidates 是候选文件数，不是确定匹配数；悬停数量可查看文件和证据片段的区别。清空搜索可恢复完整目录树。

点击带行号的结果，会在带左侧行号的文本预览中定位并高亮该行。Markdown 保留原始行号（包括 front matter）；HTML、EPUB、PDF、Office 显示索引所用的提取文本行号。关闭 Source lines 或 Extracted text lines 可返回排版阅读。文件改变导致原行不存在时会明确提醒。超长文本最多显示命中附近的 20,000 行，完整内容可用 Open original 打开。

结果是候选内容和来源证据，分数不代表事实可信度。重要结论应通过 Open original 或原文预览复核。

文件、预览与转换

类型目前支持
Markdown / HTML渲染预览、front matter、表格、代码高亮、Mermaid 图。HTML 会清理脚本和危险属性；Markdown 中的原始 HTML 作为文字显示。
PDF嵌入原生 PDF 页面预览，并提取原生文字供检索。展开“Extracted text”可看提取结果；扫描 PDF 需要 OCR，当前不会自动执行 OCR。
OfficeDOCX、XLSX、PPTX 与部分 OpenDocument 格式的文字提取和简单预览；macOS 的 textutil 处理 DOC / RTF。复杂排版、图表和公式不会完整复现。
图片PNG、JPEG、GIF、WebP 等已知嵌入格式可预览；RAF 等相机 RAW 格式会明确提示使用 Quick Look 或原生应用。所有格式仍可做标签和描述检索；本地模型支持的图像可做语义检索。
视频受 WebKit 支持的本地视频播放；FFmpeg 提供带时间范围的切片，再由多模态模型建立向量。点击有时间证据的结果，从相应位置预览。
音频受支持的音频播放；已有转写或可选 Whisper 语音识别让语音内容参与文字与语义检索。WeMM 不直接编码音频波形。
EPUB按阅读顺序显示章节文字；CLI 可把知识库中的 Markdown 和 HTML 打包为带导航的 EPUB，可选包含引用的本地媒体。
其他文件 / 二进制始终可纳入文件管理与元数据检索。没有成熟正文解析器时，请用标签和描述说明用途与内容；不会把任意二进制字节假装成可读文本。

Quick Look 请求 macOS 快速查看；是否能显示该格式由本机解码器决定。Finder 显示原件所在位置。File details 显示实时路径、文件类型、可读大小、创建与修改日期，并提供标签和备注编辑器；Copy path 与 Copy relative path 可复制完整路径。日期按本机时间显示，不可用时会明确说明；查看时不会读取整个索引或计算文件哈希。Open original 用已安装的原生应用打开文件，适合复杂 Office 文档、不支持的媒体编码或需要完整排版的 EPUB。预览不会执行导入文件中的脚本，也不会加载远程图片。

Markdown／HTML 中的章节链接可滚动到当前文档标题；知识库内的相对文件链接在应用中打开，文件夹链接定位到目录树。明确点击 HTTP(S) 链接会交给系统浏览器；它不会在预览中加载远程页面。带凭据、危险协议、越过 root 或指向内部状态的链接会被拒绝。源文件中的脚本仍不能执行。

依赖、语音模型与多模态模型

内置功能无需额外安装

文件管理、标签、文字索引、BM25、Grep、Markdown／HTML 渲染、PDF 文字提取和 EPUB 读写均包含在应用中。macOS 提供 PDF、媒体和原生应用查看能力。没有 Homebrew 或本地模型，也能使用这些基础功能。

左侧的 Homebrew 按钮安装什么

  • FFmpeg：视频切片、音频格式转换；同时需要 ffprobe 获取媒体信息。
  • whisper.cpp：可选语音识别可执行程序。安装可执行程序之后，仍需准备本地模型文件。

检测显示可执行文件的位置，不代表模型已经加载或完成了一次推理。应用优先检查 Apple Silicon 常用的 /opt/homebrew/bin，并兼容已有的 Homebrew／PATH 工具位置。

点击“在终端安装”按钮后，应用把固定的 Homebrew 安装命令交给可见的 macOS 终端窗口。终端显示安装进度、输出、交互输入和结束结果；应用只确认启动请求是否接受，不会把启动成功当作安装完成。安装与应用独立运行，关闭 Omni Knowledge 后仍会继续。完成后回到这里点击“重新检查”，确认工具可用。

安装会通过 Homebrew 联网下载软件；不会下载 AI 模型、自动启动服务或修改知识库配置。没有 Homebrew 时，先打开左侧官方说明，在终端完成安装，再点击“重新检查”。

接入已有的本地 WeMM 服务

图像、视频和文字语义检索使用独立的本地 WeMM 服务。当前配置默认连接 http://127.0.0.1:18789，并检查模型身份是否与知识库配置一致。应用不会自行下载或启动这个服务。

  1. 在已有的 embedding-wemm 项目中启动兼容的服务，例如 ./scripts/serve.sh gpu。
  2. 确认知识库的 omni-knowledge.json 中 embedding 配置与服务身份一致。用 CLI 的 doctor --embeddings 检查本地连接。
  3. 回到知识库，在 Library 面板开启 Build semantic search index，再点击底部 Refresh index。
  4. 索引完成后，在 Search options 中使用 Meaning 或 Text + meaning。外部修改过的文件需要重新建立相应向量。

模型停止时仍能使用标签、File names & notes、Full text 和 Text pattern。Library 中的语义索引选项只决定这个窗口下次主动刷新索引时是否生成向量；它不会启动模型服务，也不是搜索可用性的开关，不会保存为新的知识库偏好。关闭它也不会删除所有未修改文件的已有向量。

让音频内容可检索

最简单的方式是在音频旁边放置 文件名.transcript.json，例如 interview.m4a.transcript.json：

{"segments":[{"start":3.0,"end":8.0,"text":"这一段的转写内容"}]}

也可以在知识库配置中填写已存在的 whisper_executable 与 whisper_model 两个绝对路径，然后在 Library 开启 Build semantic search index 并刷新。界面安装的 whisper.cpp 只提供前者；模型文件由你单独选择。转写是可出错的观察结果，结果中的时间位置帮助你回到录音复核。

AI Agent、CLI 与 MCP

知识库是普通文件夹，AI Agent 可以直接编辑 wiki、标签、描述和索引页。让 Agent 先读知识库里的 AGENTS.md 与 index.md，保留 raw/ 原件，修改后调用索引，并为总结保留来源链接。

CLI 位于应用包的 Contents/MacOS/omni，或源码构建的 target/release/omni。下例的 omni 指这个可执行文件或你自行设置的 PATH 别名：

omni --root /path/to/library search "知识检索" --mode bm25 --json
omni --root /path/to/library search "精确词句" --mode grep --tag 研究 --json
omni --root /path/to/library metadata raw/firmware.bin --tag 硬件 --description "设备恢复镜像"
omni --root /path/to/library index
omni --root /path/to/library index --embeddings
omni --root /path/to/library convert raw/report.pdf --output /path/to/report.md
omni --root /path/to/library export-epub /path/to/library.epub --include-media

MCP 通过标准输入／输出提供 search、index、list、status、read、metadata 和 import。在支持 MCP 的 Agent 客户端中配置以下入口；替换为你自己的真实路径：

{
  "mcpServers": {
    "omni-knowledge": {
      "command": "/path/Omni Knowledge.app/Contents/MacOS/omni",
      "args": ["--root", "/path/to/library", "serve-mcp"]
    }
  }
}

MCP 的 list 仅返回发现文件所需的元数据；read 返回有长度上限的提取文本。软件返回来源证据，不会自动替 Agent 生成答案或接受文件中的指令。

目录、备份与嵌套知识库

knowledge/
  omni-knowledge.json    Root configuration
  index.md              Navigation
  log.md                Change history
  AGENTS.md             Agent workflow
  raw/                  Original source files
  wiki/                 Authored concepts and source references
  .omni/metadata/       Editable tags and descriptions
  .omni/indexes/        Rebuildable search generations

请备份原始文件、wiki、配置和 .omni/metadata/。索引和临时媒体切片是派生数据，可重建；恢复备份后运行索引即可重新生成缺失的派生目录。

每个文件由最近的知识库 root 管理。父库操作不会自动吞并子库；CLI 的 search --recursive 和 index --recursive 可跨嵌套库操作，结果保留各自的 root 身份。

通过本应用复制或移动普通文件时，可编辑标签和描述会迁移到目标路径，旧 sidecar 保留。外部工具移动、编辑或重命名后，请刷新索引并检查元数据；索引属于知识库内部的派生状态，整个知识库移动后仍可打开并刷新。

当前版本的边界

  • 面向 Apple Silicon macOS；M5 Pro 上已有实际运行检查，另一台 M3 Mac 仍需自己的运行验证。
  • 文字提取有 8 MiB 源文件／输出上限；过大或无法解析的文件仍可按文件名、标签和描述检索。扫描 PDF 的 OCR 为后续可选能力。
  • Office 预览为文字预览；EPUB 预览不复现出版样式、固定版式或交互内容。
  • 本地媒体是否可播放取决于 WebKit 支持的编码。单次预览资源读取上限 32 MiB；支持范围请求的媒体可分段加载，更大的非分段资源请用原生应用。
  • GUI 浏览按需读取目录且没有任意文件数量截断；GUI／CLI 单次索引查询最多返回 10,000 条匹配，全部保留原排名和行号／时间证据。GUI 暂未提供图片查询选择和 EPUB 导出按钮，这两项可使用 CLI。
  • 精确向量检索与 JSON 快照优先保证结果透明；大规模个人文件库的速度和召回率仍需用你的真实数据测试。
  • 没有内置自动 wiki 合成、文件夹事件实时监控、云同步或自动模型下载。定期元数据检查只提示可能需要刷新；索引完成与检索命中不能替代原文核实。

遇到问题时

现象下一步
没有检索结果先点击搜索输入框尾部的清除按钮，回到完整实时文件树确认原件存在。新文件尚未索引时不会出现在索引搜索中；清空标签过滤，再刷新索引。Text pattern 检查原文模式，Full text 适合关键词相关性。
显示“no index”或索引目录缺失打开正确的知识库 root，点击 Refresh index。配置文件和原件应保留，派生索引可以重建。
一直显示“Opening knowledge folder…”检查 macOS 是否正在等待访问“文稿”“桌面”或“下载”目录的权限确认；对你选择的知识库允许访问，或使用 Library 面板的 Choose 选择目录。应用重新签名后可能再次请求授权；不要绕过系统权限。
Meaning / Text + meaning 报错确认本地服务运行且身份匹配，再在 Library 开启 Build semantic search index 并刷新。使用 CLI doctor --embeddings 获取检查结果。
视频或语音索引缺少覆盖左侧重新检查 FFmpeg / ffprobe；音频还需转写 sidecar，或同时配置 whisper-cli 与本地模型。
终端未打开或安装失败启动请求失败或未确认时，先看左侧交接记录，再确认终端是否已经打开；安装中的错误与结束结果在终端查看。缺少 Homebrew 时先按官方说明配置；联网、磁盘、权限或编译问题需要在本机解决，完成后重新检查依赖。
无法完整预览文档尝试 Quick Look 或 Open original 查看原始文件。提取状态和警告说明当前检索覆盖，不会宣称未读到的内容已经被索引。
提示另一个写入者正在工作等待另一个索引或元数据写入完成，再重试。让外部 Agent 完成文件编辑后再统一刷新。
