# Package owner interface

This file is the handoff for storage, history, processing, and retrieval. It is not a second Git engine or a destination writer.

## Admission

Fetch `d51cdde` (`knowledge_core::admission`). Do not start another account.
`Work` borrows one `Holding` from `Account::current`.
`Holding::grow` runs before a retained buffer. `Holding::written` runs after generated bytes are on the private volume.
A scratch buffer reserves its own holding on that same account and `finish`es only after the buffer drops.
Dropping a holding releases nothing. This crate does not `finish` the caller's holding.
`Decision::Waiting` is `Error::Waiting`. `TooLargeMemory` and `TooLargeStorage` are `Error::TooLarge`.

## Restore

`apply` calls `SafeApply::apply_text_change` for core text and `SafeApply::install_new` for original bytes.
Those are the storage-owner operations. This workspace does not contain a committed `knowledge-storage` crate, so this crate does not link `Store::install` and does not write the destination.
Conflicts and indeterminate results stop the call. Already saved paths are not rolled back here.

## Git

Consume only the history seam fixed in `2c86db6`: `prepare`, `publish`, `inspect`, and `prepare_confirmation`.
Publication in that commit checks the confirmed proposal inside the native transaction.
This crate does not call history and does not run `git`.
`GitTransactions::admit_inert_bundle` only hands the staged bundle path to that owner.
`2c86db6` has no `git bundle verify` and does not admit an arbitrary imported repository. A bundle stays inert until that owner verifies it. `GitAdmit::Inert` is not a verified import.

## Index

Package indexes are STORED and are not installed into the home.
`compatible: true` is `Unsupported`. Querying a STORED index is the retrieval kernel's Directory provider, not a function of this crate.

## EPUB

`docs/specs/package.md` keeps EPUB as a processing operation, not a snapshot preset.
`knowledge_processing::read_epub` and `export_epub` own that result. This crate has no EPUB function and assigns no snapshot id to one.

## Not claimed

SSH `Signature::Unverified` is not trust. `v1_import_plan` returns `CompatibilityRefused` and does not invent owner, revision, or review facts.
